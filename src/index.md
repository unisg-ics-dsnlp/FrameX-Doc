# FrameX-Doc

This is the official Documentation of FrameX - a tool build by the NLP-LAB for the Hybrid AI Course at the HSG. FrameX is a domain-neutral frame-logic engine that derives knowledge from facts and rules, answers queries and explains its reasoning.

FrameX has the following parts:
- [FrameX-UI](./parts/framex-ui.md): A Web-Interface to use FrameX and its logic engine
- [FrameX-CLI](./parts/framex-cli.md): A interactive CLI interface that lets you use FrameX locally on your device.
- [Hackable-FrameX](./parts/hackable-framex.md): The core FrameX-Engine, designed to be used in Hackathons and other projects.
- [FrameX-Engine](./parts/framex-engine.md): The core frameX engine that drives all the other parts.
- [FrameX-Doc](./parts/framex-doc.md): The Documentation that you are currently reading.
