# Quick reference: choosing the right construct

Use this page to choose a representation for the question you want to
answer. Return to the corresponding lesson for a complete executable
example.

| Your modeling task | FrameX construct and meaning |
| --- | --- |
| Identify an entity | Give it a stable object name. A label is a property, not its identity. |
| Classify an object | Membership uses a colon. An object can belong to several classes. |
| Describe relationships | Use named slots inside brackets. The property arrow asserts a value; it does not replace existing values. |
| Record several values | Use a value bundle or separate slot facts. Neither implies order or completeness. |
| Organize classes | Use extends for inheritance. Class structure is distinct from namespace qualification. |
| Describe a relation with an argument | Use a parameterized method. A logical method result does not execute a procedure. |
| Attach evidence to a relationship | Model the relationship as a named object with explicit roles and source information. |
| Derive a consequence | Write a rule with a head and a body. Bind variables positively and group alternatives explicitly. |
| Follow a graph path | Join frames through a shared variable. Use positive recursion for paths of arbitrary finite length. |
| Ask a question | Use an embedded query. Bind candidate objects before selecting unknown answers. |
| Check an expected answer | Use an expectation. It checks a result; it does not establish evidence. |
| Reason about absence | Declare the world and close only features whose evidence is complete in the intended scope. |
| Check data quality | Separate field types, required values and functional constraints. Validation reports issues rather than repairing them. |
| Combine knowledge sources | Use namespaces for identity and modules for knowledge contexts. Preserve evidence and completeness boundaries. |
| Understand a conclusion | Inspect its explanation and source annotations. Logical support is distinct from calibrated probability. |
| Control an agent | Derive permissions from current state and evidence. An external host performs authorized tool operations and records results. |
